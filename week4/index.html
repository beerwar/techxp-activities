Week 4: CSS Fundamentals

Learning how CSS changes the appearance of HTML.

What is CSS?

CSS stands for Cascading Style Sheets. It controls the appearance and layout of a webpage.

HTML provides the structure, while CSS adds colors, spacing, fonts, and other visual styles.
